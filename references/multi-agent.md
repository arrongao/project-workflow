# 多人和多Agent协作

本说明不自动授权创建或调度其他Agent。

## 归属与隔离

交接至少说明目标、负责人、分支/worktree、已改文件、是否提交、验证、失败尝试和下一步。未提交文件在共享目录中可能可见；独立worktree不会自动获得它们。commit只有在共享对象库或显式传递后才可被另一环境取得。

并行写入优先采用独立worktree或独立checkout，并明确文件归属。仅创建不同branch不能隔离同一个工作目录。共享只读分析可以进行；共享写入需明确协调，不能同时覆盖同一文件。不要未经授权切换别人正在使用的分支。

## 接手与结束

先读取状态和差异；内容对得上不构成接手授权。存在活动写入者或归属不明的冲突时询问；不相交的已授权工作可继续。

提交按用户和仓库规则执行。允许WIP提交，但不是默认强制动作；不混入无关改动，不自动push。用户禁止提交或暂时无法提交时，记录未提交文件和下一步，不强制清理工作区。

交接优先更新既有状态入口，较长日志用链接关联。若项目已有HANDOFF或Issue约定则复用，不另造重复事实源。
