# 四条判断（这套工作流的真正内容）

文件结构只是载体。**这四条才是要传下去的东西。**
下面每条都配了真实例证 —— 例证来自一个具体项目，**是为了说明，不是让你照搬**。

---

## 判断一：规则与状态必须分开写

**规则是持久的**：怎么构建、什么绝对不能违反、踩过哪些坑、交付要什么。
**状态每天在变**：哪些需求待办、当前进度、验收结论。

**把它们写进同一个文档，必然漂移** —— 而**一份会漂移的手册比没有手册更危险**，
因为读它的人（或代理）会照着过期信息确信地行动。

| 放哪 | 写什么 | 自检问题 |
|---|---|---|
| `AGENTS.md` / 贡献指南 | 规则 | **这条明年还成立吗？** 不成立 → 它是状态 |
| `BACKLOG.md` / issue 表 | 状态 | **这个结论会随一次提交改变吗？** 会 → 它是状态 |

**反例（真实发生）**：某项目的手册里一度混着"当前有 7 个开发开关没清理"这类条目，
后来开关清掉了，手册没改 —— 下一个人照着它去找不存在的东西。

**推论**：**做完一件事就顺手改它那一行状态。** 实现和提交都有明确的"完成瞬间"，
改状态没有 —— 它只是顺手的事，于是被留到最后，然后被忘掉。

---

## 判断二："完成"必须附**别人能复现**的证据

**不接受"应该没问题"。**

证据的最低形式：**一条命令 + 它的真实输出**。截图、测试结果、观测数据都算，**但必须可复现**。

| 不算证据 | 算证据 |
|---|---|
| "我改好了" | `--selftest`：23 通过 / 0 失败 |
| "应该能用了" | 改前 `exit 1` → 改后 `exit 0`，命令与输出都贴出来 |
| "看起来正常" | 截图，且说明在哪台机器、什么缩放下 |

**推论 A：不要自行宣布通过。** "开发完成"和"验收通过"是两件事，
**后者只有提需求的人能宣布**。

**推论 B：一个本身不可靠的测量也不是证据** —— 见判断四。

---

## 判断三：同一个错误犯两次，就把它变成规则

**不要预先写满假想的规则。** 只写**真实发生过两次以上**的。

**为什么是两次**：一次可能是意外；两次说明是**模式**。而只写模式，手册才会短 ——
**聚焦的文件比面面俱到的文件更容易被遵守。**

**每条规则的写法**（三样缺一不可）：

1. **规则本身**（祈使句：做什么 / 不做什么）
2. **它是怎么被发现的**（什么现象、什么代价）
3. **为什么不能"优化"掉它**（如果它看起来像冗余绕坑代码）

**真实例证**：某手册里有一条「占位值绝不能看起来像真值」。
它来自两次独立的事故 —— 一次是版本号写成 `1.0.0`（于是普通构建和正式包互相矛盾），
一次是打包脚本的默认参数停在上线前的占位身份（于是本地安装**必然失败**）。
两次的共同形状是「**一个看起来像真值的占位值，没人会去核对它**」。

> **注意第二条**：写清"怎么发现的"比写清规则本身更重要 ——
> 否则下一个人只会看到一个奇怪的禁令，然后把它删掉。

---

## 判断四：先怀疑测量方法，再怀疑被测对象

**这条是最难学会的，也是代价最大的。**

发现异常时，人的默认反应是"被测对象坏了"。**但很多时候是探针坏了。**

**已经见过的形状（都真实发生过）**：

| 那次测量 | 当时的结论 | 实际 |
|---|---|---|
| 日志里打印了设备列表 | 「功能正常」 | 那是**另一个东西**，不是被查的状态 |
| 只在一个主题下渲染预览 | 「控件没问题」 | 那个缺陷**只在另一个主题下出现** |
| 一次带地区参数的请求返回 404 | 「ID 是错的」 | **ID 从来没错**，是那个 URL 在该地区不可用 |
| 用 `-match 'Arron'` 查证书 | 「新证书没建成」 | 新证书的主题是 `CN=<一串 GUID>`，**不含 "Arron"** |

后两个是**同一天**发生的，而且**规则当时已经写在手册里了**。

### 可操作的规则

1. **查证"某物不存在"之前，先证明你的过滤器/探针能匹配到一个【已知存在】的样本。**
   匹配不到只说明"这次没匹配到"，**不说明"不存在"**。
2. **异常结果先怀疑测量方法，再怀疑被测对象。**
3. **用两个【独立的】判定交叉验证** —— 不是把同一个判定换个写法再跑一遍。

### 一个具体到刺眼的例子

```powershell
# 想查"这个包还装着吗"
Get-AppxPackage | Where-Object { $_.Name -match 'BluetoothBatteryTray' }
# 实际身份是 ArronGao.48686D75A2435 —— 不含这个子串
# 于是输出为空，而人读到的是"没装"，实际是"没匹配到"
```

**过滤器写的是"我以为它叫什么"，不是"它实际叫什么"。**
**先拿一个已知存在的样本跑一遍过滤器**，这一步只要三秒。
